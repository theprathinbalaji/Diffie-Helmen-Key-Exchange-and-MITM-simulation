1. Four Modes
	Common Instructions for all modes:
		Make John generate a generator and a modulus.
		Provide it to Alice and Bob.
		Let Alice and Bob generate their keys and exchange them.
		Show the key generated by the HKDF as proof of key exchange.
		John will announce the keys to Bob, Alice and Eve too.
		Terminate John.
		
		Only Alice WILL initiate chat, be it with Bob or Eve. 
		If Eve happens to exist, she will request Bob.
		Bob will accept or reject it using yY or Nn. Eve shouldn't be given a similar choice.
		
		Only Alice will enquire about the mode and tell John.
		John, along with the generator and modulus, will inform Bob of the mode(a, b, c, d).
		
		Only one mode should exist per run.
		
		Let them relay message in the format [<USER>]: \t <MESSAGE>
		
		Expected order of execution: Sniffer.py(sudo) >> Alice.py >> John.py >> Bob.py (&& Eve.py if applicable)
		
		"-1" is the key for ending the chat. Both (or three of the) parties must see their chats end at the same time. Eve can also end their chat abruptly. They other party(ies) have to get "Alice/ Bob/ Eve, the middlewoman decided to end the chat." on ending the chat.
		
	Mode a: Simple Diffie Hellman: Exchange keys and chat w/o encryption.
	Mode b: Encrypted Diffie Hellman: Exchange key and chat w AES-GMC encryption
	Mode c: MITM attack launched on Mode b. Alice deliberately(well, technically not) requests Eve for a chat.
		Eve can forward or send an entirely new message to the receiving party. (Understood by "f" for forward or "n <new message>" for new message)
	Mode d: Mode c with EA25509 assurance. The chat will not end. A label "<<EVE DETECTED>>" will be put after every received message.
		Exchange keys right after telling each other the mode.
	
	For Mode c, Alice and Bob's chats will act simply like in mode a or b, unaware of Eve. In Eve's chat, we will have "[ALICE]: ", "[EVE(ALICE)]: ", "[BOB]: " and "[EVE(BOB)]:"	
	
	Sniffer must only put out the encrypted(or unencrypted) text and the texting party as "[ALICE]: ", "[BOB]: ", "[EVE(ALICE)]: " or "[EVE(BOB)]: ".

	Avoid using the "if __name__ = __main__:" convention. 
	1-liner functions, built solely for returning smth, are not entertained.
	All functions common to Alice and Bob should be placed in "Party.py"
	
	Make the code as simple and TO THE POINT as possible. DO NOT introduce unnecessary caveats not mentioned in this document.
	Try to sort functions in the Party.py by mode.
	Write the purpose of each function in the commented '#'.

	Refer to Alice.py, Bob.py, Eve.py(built here for Sniffer.py) and Party.py for further understanding on the coding I expect.
